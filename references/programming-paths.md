# Caminhos de Projetos Progressivos – Programação

Este arquivo serve como referência para montar currículos baseados em projetos reais.

## Princípio
Cada projeto deve:
- Ser concreto e útil
- Ter potencial de virar uma ferramenta ou negócio
- Aumentar gradualmente em complexidade
- Forçar o uso dos conceitos da fase atual

---

## Progressão recomendada (exemplo para Python + APIs + IA)

### Nível 1 – Fundamentos + Utilidade imediata
**Projeto:** Script de automação pessoal
Exemplos:
- Organizador de arquivos
- Bot de lembretes no terminal
- Conversor de dados (CSV → JSON)

### Nível 2 – API Básica
**Projeto:** API simples com FastAPI
Exemplos:
- API de lista de tarefas
- API de citações / frases
- API de conversão de moedas (mock)

### Nível 3 – API + Banco de Dados
**Projeto:** API completa com persistência
Exemplos:
- Sistema de anotações
- Controle de hábitos
- Mini CRM pessoal

### Nível 4 – Autenticação + Deploy
**Projeto:** Aplicação com usuários e deploy
Exemplos:
- App de tarefas com login
- Sistema de links encurtados
- Dashboard simples

### Nível 5 – Integração com IA
**Projeto:** Ferramenta com LLM / RAG / Agente
Exemplos:
- Assistente pessoal com memória
- Busca inteligente em documentos
- Agente que automatiza tarefas do dia a dia

### Nível 6 – Solução para cliente
**Projeto:** Produto real ou MVP para cliente
Exemplos:
- Automação para um negócio local
- Ferramenta interna para uma empresa
- SaaS simples

---

## Regras de uso
- Sempre escolha o próximo projeto com base no que o aluno já domina.
- Prefira projetos que o aluno sinta vontade de terminar.
- Cada projeto deve gerar progresso visível e motivador.
