# Learning Contract

This file is the sole authority for mastery, evidence, retention, weak points, help, and spaced repetition.

## Mastery matrix

| `mastery` | Observable requirement |
| --- | --- |
| 0 | No valid evidence. |
| 20 | Recognizes terms or attempts with intensive help. |
| 40 | Partially applies a known procedure with directional help or a partial hint. |
| 60 | One autonomous Feynman explanation and one independent autonomous standard application. |
| 80 | Requirements for 60, with an autonomous application transferred to a new context. |
| 100 | Performance for 80 repeated across at least two session IDs and two contexts, including limit detection or self-correction. |

An evidence is independent when it tests a different behavior or uses a substantially different task. Evidence older than 45 days remains historical but must be reconfirmed before raising mastery.

Tutor-provided answers, copied solutions, generated cards, diagrams, images, audio, video, or other media are not evidence. A later autonomous attempt may be evidence.

## Help ladder

1. Rephrase the task.
2. Retrieve a prerequisite.
3. Ask a directional question.
4. Give a partial hint.
5. Give an incomplete skeleton or pseudocode.
6. Explain a solution.

Steps 5–6 cap that attempt at 20; steps 3–4 cap it at 40. Mastery 60+ requires attempts after only the prompt was supplied.

## Retention

`retention` is `unknown`, `low`, `medium`, or `high`. Review failure changes retention and schedules practice; it does not erase demonstrated mastery. Reduce mastery only after two recent autonomous evidences show consistent loss of the previously demonstrated capability.

## Weak points

Create a weak point when the same category recurs twice or blocks required evidence. Categories are `conceptual`, `procedural`, `application`, `precision`, and `execution`.

Resolve it after two correct autonomous evidences in different sessions. For mastery 80+, one must be transfer. Record its ID, topic, cause, supporting evidence IDs, entry date, exit condition, and status.

## Curriculum completion

Close a checklist item only when mastery is at least 80, required evidence IDs exist, the session log references them, and any explicitly required programming delivery is present.

## Spaced repetition

Intervals are 1, 3, 7, 16, 35, and 60 days. A correct answer advances one step, almost correct stays, and incorrect returns to step 1. The tutor judges objective correctness first; the student reports confidence separately.
