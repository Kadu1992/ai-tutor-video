# Sources Workflow

Prefer primary and authoritative sources: official documentation, universities, standards, original research, and established reference books. Browse when freshness, precision, or verification matters.

For each source record title, author or institution, direct URL or bibliographic identifier, publication/update date when available, access date, source type, linked lesson/topic ID, and why it is authoritative. Never invent a citation or claim access that did not occur.

Respect access rights and copyright. Create a progressive reading order when useful, including strong Brazilian Portuguese material when available.
