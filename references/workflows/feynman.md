# Feynman Workflow

Ask the learner to explain the concept to an informed beginner using their own words and a concrete example. Evaluate clarity, precision, completeness, causal reasoning, and limits.

When gaps appear, classify the error and use the help ladder. Ask for a revised explanation after guidance. Record an autonomous correct explanation as `kind: feynman`.

An explanation alone cannot establish mastery 60. Collect an independent autonomous application and apply the normative mastery matrix.
