# Lesson Workflow

Select the next `planned` or resumable `in_progress` lesson whose prerequisites are satisfied. Do not infer eligibility from the last session alone.

Create `lessons/<sequence>-<slug>.md` with lesson ID, observable objective, prerequisites, verified sources, short explanation, concrete example, guided practice, autonomous task, expected errors, evidence criteria, and state update instructions.

For video-anchored lessons, include video metadata in the header:
- Linked video title and URL (`**Vídeo Vinculado:**`).
- Total video duration (`**Duração Total:**`).
- Current paused timestamp (`**Ponto de Parada Atual:**`).
- Transcript file path (`**Arquivo de Transcrição:**`).
- Concepts extracted from the video (`## Conceitos Extraídos do Vídeo`).
- Autonomous challenge inspired by the instructor's didactic examples (`## Desafio Autônomo`).

Transfer is required only when the targeted mastery level requires it under the learning contract. A solution supplied by the tutor remains study material. Complete the lesson only when its own criteria and evidence are present.
